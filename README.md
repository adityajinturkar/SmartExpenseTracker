# 💰 SmartExpenseTracker

An AI-powered Expense Tracker built with the MERN Stack to manage income and expenses with interactive dashboards and AI-generated financial insights.

## 🚀 Features

- User Authentication (JWT)
- Add, Edit & Delete Transactions
- Dashboard & Charts
- AI Financial Insights
- Export to PDF & Excel
- Dark Mode
- Responsive UI

## 🛠 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **AI:** OpenRouter API
- **Authentication:** JWT

## ⚙️ Run Locally

```bash
# Backend
cd server
npm install
npm run dev

# Frontend
cd client
npm install
npm run dev
```
